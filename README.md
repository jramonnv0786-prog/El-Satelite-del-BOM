# El-Sat-lite-del-BOM
Vais a desarrollar un sistema compuesto por dos archivos HTML (index.html y satelite.html) y un documento de análisis en Markdown (analisis.md). El objetivo es poner en práctica la interacción real entre ventanas del navegador, la detección del entorno, el control del historial y la identificación de los objetos predefinidos del lenguaje.
